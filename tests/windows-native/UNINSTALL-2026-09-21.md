# Windows uninstall and fresh setup, 21 September 2026

A human `dearmachine uninstall` failed before confirmation because the Windows
removal preflight rejected a junction generated by the installer's own DSH
profile: `dsh/profiles/node_modules/zod-to-json-schema`. No uninstall was started.
The same failure was reproduced through ConPTY in the ordinary-user profile
previously used for the successful live installation and email tests.

Umbrella `d4ada957` makes preflight inspect child junctions without following
them. Native recursive removal deletes those links without traversing their
targets. Redirected roots and ancestors remain refused. The native regression
has five cases covering generated, dangling and cyclic junctions, external data,
redirected roots/ancestors, long Unicode paths and repeat removal. Four cases
failed against the old helper; all five passed with the fix. A separate native
PowerShell check confirmed workspace marker enumeration did not recurse into
an external junction target.

The actual managed runtime then passed cancellation and confirmed asynchronous
uninstall. Software and DearMachine configuration/state were absent afterward;
the external file reached through a generated-profile junction survived.
The test waited for the cleanup result, not just the launching command's exit.

A fresh reinstall exposed a second failure. Native status reported DearMachine
absent, but bare launch refused setup because independent `.machtiani` project
stores and modes remained. Windows uninstall intentionally preserves that data.
DearMachine `764e206` makes Windows bare-launch detection use DearMachine's own
state. Independent Machtiani data no longer blocks setup; actual partial or
unreadable DearMachine state still requires recovery. Linux behavior is unchanged.

The native Windows routing regression failed against the old implementation and
passed with the correction. The canonical focused runner also passed using
native Go 1.26.5 and Zig/CGO. It selects production Windows files because the
command package also contains pre-existing Unix-only test fixtures. The native
product was rebuilt with the same pinned toolchain. All 23 Linux Nix flake checks
passed on DearMachine `3dc9ba4`, including the Go suite and lifecycle gates.

The final prepared runtime uses umbrella `1fae8512`, DearMachine `3dc9ba4`,
Installer `deea0d7` and Harness `2890e6181`. The native `reinstall.ps1` gate verifies
confirmed uninstall, reinstall, actual fresh-setup consent through ConPTY, a
credential-free decline, and confirmed removal again. An independent Machtiani
project survives the complete cycle. Generated-profile links are present during
both cancellation and confirmed removal. All asynchronous cleanup completes.

These are native lifecycle and routing tests with a prepared runtime. They make
